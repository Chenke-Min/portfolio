## 两个项目

### 01 · 帮帮匠工程排障助手

现场问题信息不完整，导致反复追问和跨角色交接。**产品判断是把深入研判从施工端移到 PM 端** —— 施工端负责说清事实，PM 端结合案例与证据完成研判、分流和后续办理。

| 关注点 | 位置 |
|---|---|
| 人机分工的取舍 | [业务流程](project-1.html#workflow) |
| 交互原型 | [原型演示](project-1.html#prototype-demo) |
| 内测数据与口径 | [内测数据](project-1.html#outcomes) |
| 评测、成本与放行判定 | [评测与成本](project-1.html#validation) |

**证据分层**：本地 81 项断言验证流程与页面；96/120 现场评测验证模型质量；两者分开取数。

### 02 · 建言献策建设项目咨询助手

产业研究需要反复查找政策、项目和规范资料。**产品判断是按任务路由双源检索**，并把「没有可验证依据」显式做成拒答分支，而不是强答。

| 关注点 | 位置 |
|---|---|
| 功能模块与首期范围 | [原型展示](project-2.html#prototype) |
| 双源路由与拒答规则 | [AI 方案](project-2.html#rag) |
| 指标定义与测试设计 | [评测设计](project-2.html#evaluation) |
| 成本约束与推广判据 | [成本考量](project-2.html#cost) |
